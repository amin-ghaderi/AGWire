# AGWire

A modern news web application built with React, ASP.NET Core Minimal API, and NewsAPI.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Query
- ASP.NET Core Minimal API
- NewsAPI

## Features

- Top headlines
- News search
- Article details
- Responsive layout

## Run

Backend

```bash
cd backend/AGWire.Api
dotnet run
```

Frontend

```bash
cd frontend
npm install
npm run dev
```
